## 五、重要发现：本地 bench 与 OJ 口径不同
  case      本地     OJ本队   OJ best
  Case1    4.518     5.72     2.12
  Case2    4.372     4.56     2.12
  Case3    4.388     4.28     2.48
  Case4    5.208     4.32     2.48
  Case5    4.481     7.74     4.36

  本地 spread 0.84us（几乎持平）vs OJ spread 3.46us（明显 shape 相关）
  Case5: 本地 4.48 vs OJ 7.74 → 本地快 3.26us

根因：本地用 aclrtEventElapsedTime 测 1000 次连续调用均摊
（mhc_bench.cpp:123-134），不含 launch/H2D 开销；OJ 测 per-call 端到端。

→ 本地数字可做相对比较（版本 A vs B），不可直接对标 OJ 分数
→ OJ Case5 那 3.26us 额外开销不来自 kernel 本身，为 F2.6 的 floor 分析
  提供了新的独立线索

## 六、两个必须避开的坑（已写入文档）
1. $HOME 会被本地 Git Bash 提前展开 → 远端报 mkdir '/c' 失败。用绝对路径。
2. 带 heredoc/多层引号的复杂命令会让远端 shell 卡死。命令保持单行，复杂逻辑走 push。
